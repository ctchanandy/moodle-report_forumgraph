Forum Graph Report for Moodle 5.0
-------------------------------------

===ABOUT===
The Forum Graph Report analyses interactions in a single Forum activity and creates a force‑directed graph with the following features:
- Each node is a single user (node size depends on the number of posts).
- Each edge represents replies between users (thickness indicates the number of replies; optional arrows show direction).
- Zoom/pan with fit‑to‑graph and PNG export.
- Sidebar controls for labels, colors, sizes, and layouts.
- Tooltip shows posts, discussions, replies, role, and last‑seen time.
- Click a node to open the standard log report for that user in the forum.

===COMPATIBILITY===
Requires Moodle 5.0 (build 2024042200) or later.

===PRIVACY===
This report does not store personal data. It reads existing forum and user data to render the graph.
